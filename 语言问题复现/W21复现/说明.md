# W21 复现说明（结论：无法稳定复现）

**原始现象**：在 `网络服务营造/后台.jsh` 里，`后台_建关系缓存` 中
`idx[内建_文本(子["id"])] = 子` 报 `E0301 找不到名字「内建_文本」`；
把 `内建_文本` 换成内建 `文本` 即通过。同文件里 `后台_搜索` 用 `内建_文本(...)` 却正常。

**尝试过的复现**（都**没能重现**，即都正常）：
1. 脚本级：`t[键(2)] = "值"`（`键` 是同文件函数）—— 正常。
2. 包内跨模块：`d[取键(2)] = "值"`（`取键` 在兄弟模块）—— 正常。
3. 包内跨模块 + dict 索引：`idx[取键(子["id"])] = "值"` —— 正常。

**怀疑**：可能只在那个大文件里、某种解析/载入顺序下偶发；或与 E5（跨模块行号错标）叠加导致误判位置。
**给语言作者**：若能量产复现，优先查“下标赋值目标里的索引表达式，名字解析是否走了与 RHS 不同的分支”。

**框架侧的稳妥写法**：这种“下标赋值的索引里要调函数”的地方，先用局部变量接住索引：
`令 k = 内建_文本(子["id"]); idx[k] = 子`，或直接用不冲突的内建。

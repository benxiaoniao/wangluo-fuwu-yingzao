# 网络服务营造

**基石语言原生的全栈框架**：后端和前端都用中文基石写，一个 `jishi` 跑通。

- 后端：路由 / 请求响应 / 模板 / ORM / 表单 / 会话 / 中间件 / 认证 / 管理后台 / 文件上传 / 开发服务器（对标 Django）
- 前端：**组件也用基石写**，经官方 `jishi_wasm.wasm` + `jishi-wasm.js` 在浏览器里运行，
  用 `浏览器` 模块操作页面、`网络` 模块调后端
- 通用能力：JSON 请求体/响应、405/HEAD、跨域 CORS、一次性提示（flash）、口令哈希登录 + 登录守卫、文件上传（multipart / base64）、ORM 分页/联表、自动管理后台、**二进制响应/二进制静态文件**、**静态 ETag·304**、**开发服务器自动刷新（改模板/静态浏览器自动重载）**

> 版本 0.3.0 · 适配基石 0.3.7 · 零第三方依赖（只用基石标准库）
> 用上的基石新特性：0.3.6 `构造响应` 字节正文与对列表头（M219）、模块级状态直接写；0.3.7 `路径.监视`（M233）+ `启动非阻塞` 做自动刷新、块级作用域语义。

## 快速开始

### 1. 准备本地包 junction（一次即可）

在仓库根 `D:\code\营造框架` 执行（或直接双击 `准备环境.bat`，它还会顺带拷 WASM 运行时并跑冒烟）：

```powershell
mkdir .jishi\packages -Force
cmd /c mklink /J .jishi\packages\网络服务营造 网络服务营造
```

> 新克隆的仓库没有 `示例/博客/静态/前端/` 下的 `jishi-wasm.js` / `jishi_wasm.wasm`
> （大文件且与 jishi 版本绑定，不入库）——跑一次 `准备环境.bat` 会从本机 jishi 安装拷过来，
> 没有它 `/前端` 页起不来，其余功能不受影响。

> 基石按「当前工作目录」找本地包，所以**所有 jishi 命令都要在仓库根目录下运行**。

### 2. 跑示例博客

```powershell
# 在 D:\code\营造框架 下
jishi 示例\博客\manage.jsh
```

然后浏览器打开：

- <http://127.0.0.1:8092/>            首页（服务端渲染的文章列表）
- <http://127.0.0.1:8092/文章/新建>    写文章（表单校验）
- <http://127.0.0.1:8092/前端>         **前端演示**：基石组件（经 WASM）拉取 /api/文章 并搜索

### 3. 跑冒烟测试

```powershell
jishi tests\冒烟_核心.jsh
jishi tests\冒烟_路由.jsh
jishi tests\冒烟_模板.jsh
jishi tests\冒烟_模型.jsh
jishi tests\冒烟_表单.jsh
jishi tests\冒烟_会话.jsh
jishi tests\冒烟_扩展.jsh
```

## 写你自己的应用

新建一个入口脚本（例如 `我的应用.jsh`），在仓库根运行：

```python
导入 网络服务营造 从 本地包 为 网造
导入 时间

# 1) 定义模型（字段名列表；id 自动加）
网造.模型_设库("我的应用/blog.db")
网造.模型_定义("文章", ["标题", "正文", "浏览数"])
网造.模型_迁移()

# 2) 写视图：函数(请求, 路径参数) -> 响应
函数 首页(请求, 参数):
    文章列表 = 网造.模型_全部("文章", 空, "id", 真)
    返回 网造.渲染("列表.html", {"文章列表": 文章列表})

函数 详情(请求, 参数):
    文章 = 网造.模型_取ID("文章", 参数["文章id"])
    如果 文章 == 空:
        返回 网造.未找到()
    返回 网造.渲染("详情.html", {"文章": 文章})

# 3) 配路由
令 路由 = 新建 网造.路由表()
路由.加("/", 首页, ["GET"], "首页")
路由.加("/文章/<int:文章id>", 详情, ["GET"], "详情")

# 4) 启动
令 配置 = 网造.核心_默认配置()
配置["路由"] = 路由
配置["数据库"] = "我的应用/blog.db"
配置["模板目录"] = "我的应用/模板"
配置["静态目录"] = "我的应用/静态"
配置["端口"] = 8000
网造.核心_运行(配置)
```

## API 速查

### 响应（视图里返回）
| 调用 | 说明 |
|---|---|
| `网造.响应(内容, 状态=200, 内容类型=…)` | 通用响应 |
| `网造.字节响应(字节, 内容类型, 状态=200)` | 二进制正文响应（0.3.6 字节通道；头值须 ASCII） |
| `网造.文件响应(文件路径, 内容类型, 请求)` | 按文件伺服（自动 ETag，命中 If-None-Match 回 304） |
| `网造.渲染("模板.html", {上下文})` | 渲染模板为响应 |
| `网造.JSON响应(数据)` | JSON |
| `网造.重定向(地址, 状态=302)` / `网造.永久重定向(地址)` | 重定向 / 301 |
| `网造.文本响应(内容)` / `网造.未找到(消息)` / `网造.错误响应(状态, 消息)` | 便捷 |
| `网造.无内容()` / `网造.未授权(消息)` / `网造.禁止(消息)` / `网造.方法不允许(允许们)` | 204 / 401 / 403 / 405(带 Allow) |
| `网造.文件下载(内容, 文件名)` / `网造.下载文件(路径)` | 作为附件下载（字节正文只发 `filename*`，文本正文 `filename` + `filename*`） |

### 请求（视图参数）
`请求.方法` `请求.路径` `请求.查询`（GET 字典）`请求.是GET()` `请求.是POST()`
`请求.取表单()`（解析 POST 表单）`请求.取值(键, 默认)` `请求.头(名)` `请求.路径参数`
`请求.取JSON()` / `请求.JSON体()`（解析 JSON 请求体）

### 路由
`令 路由 = 新建 网造.路由表()`
`路由.加(路径, 处理, 方法们=["GET"], 名字="")`
路径转换器：`<int:名>` `<str:名>` `<slug:名>` `<path:名>` `<uuid:名>`，默认 `<名>`=str
`路由.解析(方法, 路径)`（框架内部用）、`路由.反转("名字", {参数})`
`路由.其他方法(方法, 路径)`（405 用）、`路由.有路径(路径)`
> 框架自动处理：`HEAD` 当 `GET`（无响应体）；路径存在但方法不符 → `405` + `Allow` 头。

### 模板
`{{ 变量 }}` `{{ 变量.子.键 }}` `{{ 值|过滤器:参数 }}`（默认 HTML 转义，`|安全` 关闭）
`{% 如果 条件 %}…{% 否则如果 %}…{% 否则 %}…{% 结束如果 %}`
`{% 遍历 x 在 列表 %}…{% 空 %}…{% 结束遍历 %}`
`{% 继承 "基础.html" %}` `{% 块 名 %}…{% 结束块 %}` `{% 包含 "子.html" %}` `{% 注释 %}…{% 结束注释 %}`
过滤器：`长度 默认 连接 上限 小写 大写 去空白 整数 小数 首项 末项 计数 四舍五入 替换:旧:新`

### ORM
`网造.模型_定义("文章", ["标题","正文"])` `网造.模型_迁移()`
`网造.模型_全部(名字, 条件=空, 排序=空, 倒序=假, 条数=空)`
`网造.模型_取(名字, 条件)` `网造.模型_取ID(名字, id)`
`网造.模型_创建(名字, 记录)`（返回 id）`网造.模型_保存(名字, 记录)`（有 id 则改）
`网造.模型_删除(名字, 条件)` `网造.模型_计数(名字, 条件=空)` `网造.模型_列(名字, 字段)`
`网造.模型_分页(名字, 页=1, 每页=20, 条件, 排序, 倒序)` → `{总数,页,每页,总页数,记录们,有上一页,有下一页,…}`
`网造.模型_联表(主名字, 主键, 从名字, 外键, 条件)` → 给每条主记录挂 `_<从名字>` 列表（prefetch）

### 表单
字段：`{"名","类型"(文本/整数/小数/邮箱/选项/布尔/多行),"必填","选项们","提示"}`
`网造.表单_校验(字段们, 数据)` → `{有效, 错误, 清洗}`
`网造.表单_渲染(字段们, 提交到, 按钮, 数据, 错误)`

### 会话 / 一次性提示（flash）
`网造.会话_中间件()`（把会话挂到 `请求.会话`）
`网造.会话_设提示(请求, 级别, 文本)` / `网造.会话_取提示(请求)`（取一次即清）/ `网造.提示_渲染(提示们)`

### 中间件
`网造.中间件_加({"前置": 函数(请求)->响应或空, "后置": 函数(请求,响应)->响应})`
`网造.中间件_跨域()`（CORS，自动应答 OPTIONS）/ `网造.中间件_日志()`

### 认证
`网造.认证_哈希(口令)` → `"盐$哈希"`；`网造.认证_校验(口令, 存储)`
`网造.认证_登录(请求, 用户)` / `网造.认证_登出(请求)` / `网造.认证_当前用户(请求)` / `网造.认证_已登录(请求)` / `网造.认证_角色(请求)`
`网造.认证_守卫(请求, 登录地址="/登录")`（未登录返回 302 到登录页，视图里 `如果 g != 空: 返回 g`）
> 口令用 `加密.口令摘要`（PBKDF2）加盐哈希，不存明文。

### 文件上传
`网造.上传_解析(请求)` → `{字段们, 文件们:[{名,文件名,内容,类型}]}`
`网造.上传_保存(文件信息, 目录, 允许扩展们=空)`（服务端随机命名，防路径穿越）
`网造.上传_保存base64(数据, 目录)`（二进制：客户端先 base64）
`网造.上传_保存dataurl(预览, 目录)`（dataURL 图片：解码落盘 + 返回预览，前端 `<img>` 即时预览）

### 管理后台（admin）
`网造.后台_配置({"标题","用户","口令","关系","上传目录"})` `网造.后台_挂载(路由, "/后台")`
自动为已注册模型生成：登录、模型列表、**列表（搜索 + 点列头排序 + 分页 + 批量删除 + 导出 CSV）**、新建、编辑（关联字段下拉）、删除；以及**图片管理（缩略图 + 删除）**。未登录跳登录页。
- 搜索：`?关键词=…`（任意字段包含）
- 排序：`?排序=字段&倒序=1`（点表头切换升降）
- 关联列 & 关联编辑下拉：`后台_配置({"关系": {"员工": {"部门id": ["部门","名称"]}}})`，列表把外键显示成关联对象字段；编辑页该字段渲染成下拉选择
- 批量删除：勾选行 → “删除选中”（POST `…/<模型>/批量删除`，body `ids=1,2,3`）
- 导出 CSV：`…/<模型>/导出`（带 UTF-8 BOM，Excel 直接打开）
- 图片管理：`后台_配置({"上传目录": …})`，后台 `…/图片` 页展示已上传图片并可删除（配 `上传_记索引/读索引`）；0.3.6 起索引里有 `网址` 就用文件 URL，旧记录回退 dataURL 缩略图

### 前端（基石组件）
在宿主页用 `网造.前端_宿主页(标题, 组件源码, {"主体":…})`；
组件源码是基石代码，可用 `浏览器.设HTML/设文本/取值/绑定/请求/存本地/读本地`。
需先 `网造.前端_设运行时目录(含 jishi-wasm.js 与 jishi_wasm.wasm 的目录)`。
wasm 由 `/网络服务营造/jishi_wasm.wasm` 直接以 `application/wasm` 二进制下发（0.3.6）；旧端点 `.b64` 保留兼容。

### 静态文件（0.3.6+）
文本类（css/js/html/svg/json/txt/md/csv/xml）与二进制类（png/jpg/gif/webp/ico/woff/woff2/ttf/otf/wasm/mp3/wav/mp4/webm/pdf/zip…）统一按 `文件响应` 伺服（字节直出，头带 charset 或对应类型）；未知扩展按 `application/octet-stream`。**带 ETag**（大小+修改时间），命中 `If-None-Match` 回 **304**——wasm 这类大文件二次加载免传输。相对路径含 `..` 或 `\\` 一律 404（防路径穿越）。

### 开发服务器自动刷新（0.3.7）
调试 + `配置["自动刷新"]=真`（默认开）时：`路径.监视` 盯住模板/静态目录（递归），文件一变推进刷新版本并在控制台提示；渲染的 HTML 页自动注入 1 秒轮询脚本，版本变了浏览器自动 `location.reload()`。本宿主不支持 `路径.监视` 时自动退回普通阻塞模式。生产/演示可 `配置["自动刷新"] = 假` 关掉。
